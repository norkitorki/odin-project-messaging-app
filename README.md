# Odin Project: Messaging App

A simple messaging app which allows registered users to post messages including images in both public and private chat rooms.

## Dependencies

- [Ruby](https://www.ruby-lang.org/en/)
- [NodeJS](https://nodejs.org/en)
- [PostgreSQL](https://www.postgresql.org/) (as database store)

## Run Locally

```
git clone https://github.com/norkitorki/odin-project-messaging-app.git && \
cd odin-project-messaging-app && \
bundle install && \
npm install && \
bin/rails db:setup && \
bin/dev
```

Open your preferred web browser and visit http://127.0.0.1:3000/ to use the application
